# Calibration

Use this file before the Output, to check the statement and each canvas row. The product is invented: Crumbline, an invoicing tool for bakeries that deliver on account. Every example line is invented.

Find the weakest dimension in the draft, rewrite that line, and check again. No score is needed.

1. **Sourced.** Weak: "Crumbline is the fastest way to get paid." Strong, as a canvas row kept out of the statement: "Attribute: the invoice is sent on the day the delivery is logged. Proof: [PLACEHOLDER: proof needed]" Reason: the weak line names no source and claims a superlative nobody tested; the strong row keeps the fact and marks its missing proof, so no source is invented.
2. **Specific.** Weak: "Saves you time." Strong: "Each delivery note is photographed once, and the invoice is built from that photo." Reason: a step the buyer can picture replaces a vague benefit.
3. **Differentiated.** Weak: "The easiest invoicing tool for bakeries." Strong: "Works from the paper delivery note the bakery already keeps, with no card reader." Reason: any rival can write the weak line; the strong line names an attribute only if a rival lacks it, so check the rival's sentence first.
4. **Believable.** Weak: "Trusted by bakers everywhere." Strong: "Every invoice shows the photo it came from, so the buyer can check the amount." Reason: the weak line cites no proof; the strong line gives the buyer something to check.
5. **Keepable.** Weak: "Invoices go out within the hour, every time." Strong: "Invoices go out the same working day for deliveries logged before [PLACEHOLDER: cut-off time, owner to confirm]." Reason: the strong line states a limit only after the owner confirms the cut-off.
6. **Right buyer and moment.** Weak: "For every small business." Strong: "For owner-run bakeries that deliver to cafés on account, when the monthly invoice run is due." Reason: a narrow buyer and a moment make the line testable.
