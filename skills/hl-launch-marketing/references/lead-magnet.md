# Lead Magnets

Read when building a lead magnet. `offer.md` `acquire` picks the format for the funnel step; this file sets the build rules. For a format `offer.md` does not place, state the step you chose and why.

## Formats

- Checklist: verb-led items, a done box per item, one or two pages (heuristic default).
- Template: usable within five minutes of download (heuristic default), with a filled example and copy instructions.
- Cheat sheet: key items in bold, grouped by category, one or two pages (heuristic default).
- Swipe file: 15 to 50 curated items (heuristic default), each with a note on why it works.
- Mini-course: three to five lessons over five to seven days (heuristic default). Each lesson teaches one concept, gives an example, sets an exercise, and stands alone. Lesson 1 must deliver a quick win in one sitting (`offer.md` `acquire`); otherwise drop this format.
- Quiz: multiple choice only, five to ten questions and three to five results (heuristic default). Score each answer against every result type with weights, not by counting buckets.
- Calculator: show the headline number without a gate; gate the full breakdown.
- Checker: never recommend replacing or buying something that its inputs show is in order.
- Audit: the scoring rubric is the product. Each finding quotes the buyer's own page text.
- Prompt pack: five to ten prompts (heuristic default), each with the input it needs, the output it gives and one worked example.
- Dataset: one file with a column dictionary and the source of each column.

Test each path of an interactive magnet end to end before launch: every result is reachable, and each input changes the result.

## Gates and capture

- Show the open part first: the preview, the first chapter, the calculator headline, or the first quiz questions.
- Gate a personal result behind email at any step; gate a full asset only at the decision step (`offer.md` `acquire`). Ask for the email after the inputs and before the result. A failed email send must not block the result.
- A partial gate (preview, first chapter, sample output) fits a full asset the buyer must sample first. State its trade-off before choosing it.
- Keep the segment (the quiz result or the checker band) with the email, so follow-up matches the result. Store only the answers the user gave.

## Delivery and page

- Deliver on a thank-you page and by email. The page confirms delivery and offers one next step.
- The magnet page shows the preview, three to five takeaways (heuristic default), one form, and an FAQ that answers whether it costs money and what format it is.

## Supporting content

- Content upgrade: write one bonus asset per how-to post, matched to that post's topic, and place its offer inline or at the end of the post.
- Exit-intent offer (shown as the reader leaves) or scroll offer: match it to the page topic.
