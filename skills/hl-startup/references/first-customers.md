# First Customers

Identify supported channels or existing contacts and label unverified ones. Rank candidate customers by pain, product fit, timing, reachable path, and evidence quality; each lists its source (URL and visible date when found online) and what is observed versus inferred. Write each outreach angle from those observed facts only. If no fact supports an angle, say so and draft a message for the whole segment instead. Draft personal outreach asking for a conversation; use visible placeholders for unknown names or details. Do not invent familiarity or send messages.

Propose behavioral success signals and weekly actions toward 10 customers. State access, conversion, and pricing assumptions; the target is not a forecast. Do not project customer counts that double week over week: each milestone is a linear step with the constraint that limits it. Propose no ads, no automation, and no guaranteed acquisition timeline.

Only from supplied channel data, judge a channel plateaued when two or more of these show on it (proposal; heuristic default): new customers per week stay flat, the cost to win one paying customer rises, engagement at the top of the funnel falls, or effort rises while output stays flat. Name the channel to start next, before the current one plateaus. For each channel, name the signal that drops it and the action that replaces it.

Open with the most reachable channel and why. Then channels, outreach approach, message draft, signals, a milestone table (week, action, success signal), and the next testable assumption.
