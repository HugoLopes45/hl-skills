# MVP Experiment

Identify the assumption whose failure changes the decision to build. Choose the smallest feature set or manual experiment that tests it. Preserve necessary safety, privacy, and accessibility constraints; list meaningful exclusions.

Propose behavioral pass and fail criteria and a 14-day sequence ending in evidence from target users where access permits. Label schedule, sample, and threshold assumptions. If two weeks is infeasible, explain the constraint and propose a smaller test.

Return, assumption first: the experiment or feature set, exclusions, criteria, and the plan as a table: day, action, evidence collected. Do not claim a design has shipped, validated demand, or guaranteed user access. No implementation or outreach.
