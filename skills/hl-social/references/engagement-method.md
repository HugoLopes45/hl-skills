# Engagement drafts

Use this file when the user supplies posts or comments and asks which to answer or what to write. Use only the supplied text; do not browse for posts. Write drafts only; the user posts each reply.

## Triage

1. Rank by fit and intent first. Fit: the author belongs to the user's target customer group, the ICP (ideal customer profile). If the target group is not supplied, say fit is unknown. Intent: the post names a problem, asks for a tool, or leaves a named competitor.
2. Then rank by comment opportunity: the user can add something specific that the post does not say.
3. Drop a post when any of these holds:
   - the author is outside the target group and is not a peer the user wants to know;
   - the post is generic motivation, a self-promotion thread, or bait that attacks a person or a group;
   - the user can add nothing beyond praise.
4. Heuristic default: drop a post older than 24 hours that has 50 or more comments. If the post age or comment count is not supplied, say unknown and do not drop the post on that rule. The user may change either cut-off.
5. Keep up to 10 posts, ranked. Heuristic default; the user may change the count.
6. Posts by target accounts the user names rank first; the drop rules above still apply.

## Comment tiers

Match the tier to the post. Do not spend a tier-1 draft on a tier-3 post.

- **Tier 1, relationship:** one specific insight or counter-example, or the user's own experience when the user supplied it. End with a question the author can answer. Heuristic default: 2 to 4 sentences, no link.
- **Tier 2, visibility:** one sharp sentence that adds a point the post lacks. Heuristic default: 1 or 2 sentences.
- **Tier 3, light touch:** a reaction to one specific line of the post. One sentence.

Never write "Great post!", a reply made only of emoji, "+1", or a link unless the user asks for one.

## Replies on the user's own post

- Draft a reply for each comment on the user's post, except bait that attacks the author or a group. In Next, advise answering comments on the day the post is published (heuristic default).
- Draft the discussion comments the user may post under the post. Each adds a fact the post does not state. Heuristic default: two or three.

## Quote posts

Quote a post only to add a data point, disagree with its mechanism with evidence, or extend it to the user's audience. Drop a quote that restates or agrees.

## Follow-up flags

Flag each author worth more than a reply: a repeat engager, a match to the target group, or a peer to follow or message. Give one line of reason for each flag.
