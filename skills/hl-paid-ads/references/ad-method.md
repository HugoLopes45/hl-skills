# Ad method

Use this file for the claim check, the policy step, and the variant method.

## Claim types

Each claim type below needs one kind of proof. Without that proof, the line becomes a placeholder.

| Claim type | Proof needed |
|---|---|
| Price or discount | The offer terms, with currency and end date, from the user |
| Count of customers, reviews, or ratings | A dated export or the platform's public page |
| Result or outcome | A case with the user's data, and the date and method |
| Superlative or ranking | A dated third-party source that names the ranking |
| Health, financial, or legal outcome | The user's compliance review; the skill does not judge it |
| Personal attribute of the viewer | The platform's current policy on personal-attribute targeting, read in this session; until then, write `unverified: check the platform's current policy` |

## Policy step

1. Name the platform the user will use. Do not switch to another platform.
2. Read that platform's current ad policy page in this session, and record its name and the date you read it.
3. Compare each line with the policy's restricted categories. Quote the category name in the Next step when a line may conflict.
4. If the policy page cannot be read, write `unverified: check the platform's current policy` next to each affected line. Do not state a policy from memory.

## Variant method

- One message per variant. A variant that carries two offers splits into two variants.
- Use the field lengths the platform's current policy page states. Without that page, use placeholders for field length.
- Name the offer and the price with their currency, as the user supplied them.
- Put the audience's problem first when the search or placement context shows it. Otherwise lead with the offer.
- Keep one call to action per variant.

## Self-check

- Each figure has a source line in the brief, or it is a placeholder.
- No line promises a result, a rank, or a guaranteed outcome.
- No line names or implies a competitor's weakness without a dated source.
- No line depends on a currency the user did not supply.
